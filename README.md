A small REST API that detects people in an uploaded image. It forwards the image to a hosted Roboflow object-detection model and returns either the raw model output or a compact summary.

## Features

- Upload an image and get people detections (bounding boxes, confidence, class).
- Two response modes: raw Roboflow response or a processed summary (people count, average confidence, per-detection confidence, image resolution, inference time).
- Interactive API docs generated by FastAPI at `/docs`.
- Dockerfile for containerized deployment.

## Tech stack

- Python, FastAPI, Uvicorn
- Pydantic for response models
- Roboflow `inference-sdk` (hosted model `people-detection-o4rdr/11`)
- Docker

## Getting started

Requires Python 3.10 to 3.12 (`inference-sdk` 0.59.0 does not install on newer versions) and network access to `https://serverless.roboflow.com`.

```bash
git clone https://github.com/XXXDoriXXX/people-detect-api.git
cd people-detect-api
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

The server starts on `http://localhost:8080` with auto-reload. Open `http://localhost:8080/docs` to try the endpoints.

### Docker

```bash
docker build -t people-detect-api .
docker run -p 8080:8080 people-detect-api
```

## Configuration

The service currently has no environment variables. The Roboflow endpoint, API key and model ID are set in `app/core/interface_client.py`, so replace the key there with your own before running.

| Setting | Location | Description |
| --- | --- | --- |
| `api_url` | `app/core/interface_client.py` | Roboflow inference URL |
| `api_key` | `app/core/interface_client.py` | Your Roboflow API key |
| `MODEL_ID` | `app/core/interface_client.py` | Roboflow model, default `people-detection-o4rdr/11` |

## API endpoints

Both endpoints accept `multipart/form-data` with a single `file` field (an image).

| Method | Path | Description |
| --- | --- | --- |
| POST | `/infer/raw` | Returns the unmodified Roboflow response |
| POST | `/infer/processed` | Returns a summary of the detections |

```bash
curl -X POST http://localhost:8080/infer/processed -F "file=@photo.jpg"
```

Processed response shape:

```json
{
  "total_people": 2,
  "avg_confidence_%": 91.4,
  "detailed_confidences": [{ "id": "...", "confidence_%": 93.1 }],
  "image_resolution": "1280x720",
  "inference_time_sec": 0.123
}
```
